# Assignment Management Platform

A browser-based assignment management platform built with HTML, CSS, and JavaScript.

## Features
- Add, edit, and delete assignments
- Fields: title, subject, due date, priority, description
- Mark assignments as completed or pending
- Auto-detect overdue assignments
- Search and filter by subject, status, and priority
- Dashboard stats: total, pending, overdue, completed
- Data persists in browser localStorage

## How to run
1. Extract the ZIP file.
2. Open the `assignment-management-platform` folder in VS Code.
3. Open `index.html`.
4. Right-click in the editor and choose **Open with Live Server**.

Alternatively, double-click `index.html` to open it directly in a browser.

## Data storage
Assignments are stored only in your current browser using localStorage. Clearing browser storage will remove them.
